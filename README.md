# Back end - Varastonseurantasovellus

Tämä on Ohjelmistoprojekti 1 -kurssin tuotoksena syntynyt Spring Boot -webbisovellus, jonka avulla asiakas voi selata ja hallita kivijalkaliikkeen varastotilannetta.

## Käytetyt teknologiat
- Java, Spring Boot, Thymeleaf, REST API
- CSS -tyylitys, Bootstrap, Google Fonts
- Postgre DB, mikä hostataan Neon:issa
- CSC Rahti
- Git -versionhallinta

## Toiminnallisuudet
- Tuotteiden ja valmistajatietojen CRUD-toiminnallisuudet
- REST API Front end:lle
- Sisäänkirjautuminen Spring Securityllä
